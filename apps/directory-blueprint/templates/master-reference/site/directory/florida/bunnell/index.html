Contractor licenses come up often in what these firms say about themselves. Haven Pools LLC, Agua Construction Company, Pool Captain Corporation, Waldhauer & Son, Inc. and Ortiz Building Contractor each state one. Florida law separates residential pool and spa contractors, commercial pool and spa contractors, and servicing contractors who repair pools but do not build new ones, so it is fair to ask which class a builder holds. A certified contractor can work anywhere in the state, while a registered one is limited to the places where it registered.
