The license numbers on these sites begin with CPC, the prefix for a pool and spa contractor. Florida law defines a residential pool/spa contractor, a commercial pool/spa contractor and a servicing contractor whose scope covers repair and servicing but not building a new pool. A number shown on a business's site is its own statement, and the state's license search at myfloridalicense.com is where a homeowner can confirm it.
