# Footprint Rules

Locked by Shawn, 2026-09-16.

- **Owned microsites are listed like any other business.** Same card, same page template, same nofollow rule on the outbound link unless the business buys a featured tier at the public price. No sitewide links, no "recommended" badge, no special placement.
- The preference is real but obscured: the directory contains every listing in the state, so owning a few of them is invisible. The boost comes from holding the SERP three ways (microsite, directory, GBP), not from links.
- The video's phrase "a PBN of sorts of sorts" does **not** go into member-facing copy.
- No Google Analytics and no Search Console property on the directory when it sits beside a microsite network. Use Cloudflare's analytics and the indexing tool's reports.
- Do not host the directory on the same Cloudflare account as the microsites when the member has more than one account available; vary registrant details where allowed. (Same rule as the Microsite Blueprint's footprint section.)
- The `owned` flag from Gate 2 exists so the report can list owned rows for the human. It must never change rendering.
